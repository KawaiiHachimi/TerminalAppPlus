# 虚拟机管理实施计划

现有 Debian 原地保留；通过独立配置选择当前虚拟机，每次只运行一台。
磁盘、启动参数和默认界面属于各自虚拟机，页面不拥有 VM 生命周期。

## 第一批：生命周期解耦（已实现）

- `VmState.Running` 表示 AVF 已启动，不再要求 ttyd 地址。
- `TerminalConnection` 单独描述连接准备、端点和连接失败；端点存在不等于 Guest ttyd 已就绪。
- ttyd 连接超过 15 秒或断开时显示提示，允许重试、打开控制台；迟到的连接成功仍可恢复页面。
- 关闭最后一个 ttyd 标签只关闭终端会话；显示“新建终端”，不停止 VM。
- 主页面 ViewModel 释放不停止 VM；通过通知中的停止操作或 Guest 关机结束运行。
- NSD 查询支持取消和超时释放，旧 VM 的异步结果不能覆盖新 VM。
- 启动与停止串行执行，停止失败时不将仍在运行的 VM 显示为已停止。
- 主界面图形按钮去掉额外的 8dp 右边距。

这里尚未统一旧的实验 Activity；它仍仅是实验功能，不是自定义镜像管理入口。

## 第二批：虚拟机配置与 U-Boot 导入

- 原地登记现有 Debian，保留磁盘、账户和配置。
- 实验室只留“自定义 U-Boot 启动镜像”，通过系统文件选择器导入。
- 导入到独立目录，检查空间和格式，失败/取消清理未完成的副本。
- 生成独立配置，使用统一后台运行器和当前 VM 控制台；关闭控制台不停止它。
- 设置中选择当前虚拟机；切换运行中的 VM 先明确处理关机。
- 切回默认 Debian 不重置磁盘，不共享可写系统磁盘。

## 第三批：初始设置与高级配置

- 首次启动选择下载 Android 预构建 Debian 或导入镜像。
- 自定义镜像选择 U-Boot 或直接内核启动；后者提供内核、可选 initrd 和参数选择。
- 每台 VM 设置默认进入 ttyd、控制台或图形界面。
- 表单与 `vm_config.json` 统一来源，校验后保存，重启生效，保留上次可用配置。
- CPU 先支持已验证的单核/匹配宿主，指定核心数需设备验证后开放。
- 官方 Debian 初始化仅用于官方配置，不自动改动自定义镜像的用户或服务。

## 验收重点

- ttyd、Guest agent 或图形服务不可用时，VM 仍可由控制台操作。
- 关闭最后一个标签、退出主页面、重新打开不会造成 Guest 重启。
- VM 停止后到达的旧连接结果不能把界面改回运行中。
- A/B 切换磁盘隔离；切回官方 Debian 内容不变。
- 导入失败和配置校验失败不破坏上一台可用虚拟机。
