# QPR3 MD3 界面移植（开发分支）

本轮参考 Pixel QPR3 TerminalApp 的主界面、设置页和标签栏组件，在现有 Kotlin/Compose 工程中实现，不加入反编译的 Compose/R8 Java。
提取 APK SHA-256：`a2ed91f6ae903e9fef3f8cc550e9baca4b5dc8fdcaa213558f5396f94867c033`，cidata build ID `16583637`。

## 当前范围

- 主界面采用 MD3 表面色阶、圆角活动标签、底部圆角连接、动态标签宽度和更多菜单。
- 设置作为可切换、可关闭的标签显示，设置列表采用分组卡片；保留 Plus 的虚拟机、端口、高级、恢复和项目入口。
- 设置标签与终端标签共用 VM，不额外启动 VM；关闭最后一个 ttyd 标签后仍保留现有空白页行为。
- 保留控制台直达、虚拟显示器、浮动控件等已实现功能。
- 尚未移植 QPR3 的标签拖动和多窗口能力。

## 固定终端样式

App 主界面和设置随系统浅色/深色模式变化；终端本身始终深色：

- ttyd 固定 Dracula，不提供主题选择、浅色终端、主题导入或外观设置页。
- 保留上一版已选择的字体；新安装默认读取 `/system/fonts/DroidSansMono.ttf`，不可用时回退等宽字体。不内置默认字体。
- 原生控制台恢复原有固定黑底、等宽字体和双指缩放字号记忆。
- 保留 ttyd 已有缩放与字号记录，不再提供字体/主题管理入口。

主题解析器、其他预设、导入页面和相关资源均已移除。升级时不删除用户文件。

## 图标

沿用新版图标轮廓与白色符号，把所有有色像素统一映射为蓝色色相，保留明暗渐变、尺寸和透明度。
可用 `tools/recolor-terminal-icon.py` 与原 APK 解码后的 res 目录复现（开发机需 Pillow）。

本轮不替换 cidata、VM 后端、镜像管理或 Guest Tools，不加入 Wayland/SFTP 等 QPR3 后端能力。
